# Paint Bucket

Paint bucket tool mod for the GD editor.
Automatically fills closed shapes in the editor.

<img src="logo.png" width="150" alt="Paint Bucket" />

## Features
- Automatically fill closed shapes
- Custom color support (#RRGGBB)
- Undo / Redo support

## Build instructions
```sh
geode build
```
